# SudokuSpace.com

A simple, responsive Sudoku game by Lucas Olmeta built with React.

## Features
- Generates a new Sudoku puzzle
- Editable cells with input validation
- Check button highlights correct and incorrect entries
- Alert when the puzzle is fully solved
- Responsive layout (scales with window size)

## Tech Stack
- React
- JavaScript
- CSS Grid / Flexbox

## Play Online
[`SudokuSpace.com`](https://SudokuSpace.com)

## Run Locally
```bash
npm install
npm run dev
